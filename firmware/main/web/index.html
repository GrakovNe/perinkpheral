Wi-Fi

The device restarts and joins this network. If it cannot, its own access point comes back after two minutes.

Time

A POSIX time zone, the way the device keeps it. The button fills in the zone of the computer or phone this page is open on.

Firmware

A new image is kept only if the device comes back reachable; otherwise it returns to the one it runs now.

Reset

Forgets the Wi-Fi network, every setting and everything the applications stored. The device comes back with its own access point, waiting to be set up.
